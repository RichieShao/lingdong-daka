# 灵动打卡 · 产品需求文档（PRD）

> 文档驱动：本文件在写任何代码前与用户确认，作为验收基准。

## 1. 产品定位
个人学习打卡工具（移动端 H5）。帮助用户**坚持学习、管理科目与任务、追踪目标倒计时**，并通过**积分激励**形成正反馈闭环。

## 2. 目标用户
学生 / 自学者，需要一个轻量、随时可用、打开就能用的学习管理工具。

## 3. 核心功能清单

| # | 功能 | 说明 | 验收点 |
|---|------|------|--------|
| F1 | 学习打卡 | 按科目打卡，记录时间，自动 +积分，计算连续打卡天数（streak） | 打卡后积分↑、历史↑、流水↑、streak 更新 |
| F2 | 学习科目 | 增 / 删 / 改科目（语文/数学/英语/…），每科配色 + 图标 | 列表即时更新并持久化 |
| F3 | 学习任务 | 任务清单，关联科目，可设截止日，完成得积分 | 完成→积分↑、流水记录；可标记/删除 |
| F4 | 倒数日 | 添加目标日期（考试/事件），显示剩余天数 | 首页+列表显示「剩 N 天」；过期显示「已到期」 |
| F5 | 首页走马灯 | 轮播展示语文/数学/英语的**实用名言、公式、英语语法** | 自动轮播 + 可手动切换；内容按科目分组 |
| F6 | 积分功能 | 积分余额展示；打卡 / 完成任务获得 | 余额与流水一致 |
| F7 | 历史记录 | 打卡历史按日期倒序列表 | 可按科目筛选 |
| F8 | 积分流水 | 积分收支明细（获得 / 消耗、金额、原因、时间） | 与每笔操作对应 |

## 4. 非功能需求
- 移动优先响应式，手机体验优先，断点 ≤480 / 768 / 1024 / ≥1280 均正常。
- 数据本地存储（localStorage），离线可用、刷新不丢。
- 中文界面，零构建、双击 `index.html` 即跑。
- 适度微交互（打卡动效、走马灯切换、弹层过渡）。

## 5. 积分规则（v1）
- 打卡：+10；连续打卡第 3 天额外 +5，第 7 天及以上额外 +10。
- 完成任务：+20。
- 每笔收支写入积分流水。

## 6. 范围外（v1，后续按 fullstack-dev 升级）
- 多端云同步、账号系统、后端服务、分享、提醒推送。

## 7. 验收总标准
- [ ] 首页走马灯自动轮播 + 手动切换正常
- [ ] 打卡后积分 / 历史 / 流水 / streak 同步更新
- [ ] 科目 / 任务 / 倒数日增删改即时持久化
- [ ] 四个断点均正常显示
- [ ] 刷新页面数据不丢
- [ ] 可部署到云端取得在线可访问链接
